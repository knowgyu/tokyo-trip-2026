# 도쿄에서 보낼 4일

2026년 11월 11~14일, 성인 2명의 도쿄 여행 수첩.
항공·2인 1실 숙소 비교, 동네 지도, 식당·카페·명소 선택과 4일 시간표 생성을 제공하는 정적 웹페이지입니다.

## 수록 내용

- 숙소 32곳. 기본 필터는 3박 표시 합계 100만 원 이하인 26곳입니다.
- 식당 32곳, 카페 24곳, 명소·산책·행사 41곳.
- 객실·시설·취재·여행자 사진 갤러리. 각 사진에서 출처와 제공된 작가·라이선스를 확인할 수 있습니다.
- 항공·숙소·장소·내 일정으로 나눈 화면. 숙소 최대 3곳 나란히 비교.
- 지도·사진 목록이 같은 동네·종류·메뉴·실내외 필터를 사용합니다.
- 날짜별 방문 순서 지도, 선택 숙소 위치, 모바일 지도/목록 전환.
- 나리타·하네다 고정 핀, 공항/시내 화면 전환, 기본 숙소 후보 표시.
- 지도 안 숙소 사진 넘기기·3박 요금·후기·선택, 공식 객실/주변 메모, 구글 주변 로드뷰 연결. 넓은 화면에서는 상세 카드가 지도 옆에 표시됩니다.
- 영업일·식사 시간·공항 이동을 고려한 4일 시간표. 목·금 방문 순서와 날짜 변경.
- 선택·예산·시간표 파일 저장·불러오기, 선택을 담은 공유 링크, 4일 인쇄/PDF.

선택한 장소와 일정은 방문자 각자의 브라우저에 저장됩니다. 공유 링크는 자동으로 기존 선택을 덮어쓰지 않습니다. 전체 선택을 불러오거나 담은 장소만 추가할 수 있습니다. 파일 저장·불러오기로도 옮길 수 있습니다.
항공·숙소 금액은 2026-10-28 조회 당시 표시가이며 실시간 예약 가격이 아닙니다. 호텔 별도 세금이 명시된 경우 합산했고, 미확인 추가요금과 회원가 조건은 카드에 표시했습니다.
후기 척도는 출처별로 구분하며 다른 서비스의 점수를 합산하지 않습니다.

## 실행

루트를 정적 HTTP 서버로 열면 됩니다. 빌드나 API 키는 필요하지 않습니다.
GitHub Pages는 main 브랜치 루트를 게시합니다.

## 자료와 라이선스

- 지도: Leaflet 1.9.4 (BSD-2-Clause), OpenStreetMap contributors (ODbL).
- 글꼴: Pretendard. assets/의 라이선스 파일 참조.
- 장소·사진·후기·좌표의 출처는 화면 안에 표시되어 있습니다. 외부 사진은 원 출처에서 제공됩니다.
- 날씨 예보: Open-Meteo. 예보가 없는 날짜는 일본 기상청 평년값을 표시합니다.
- 일정 이동 시간은 시설 좌표·지역 기준 추정입니다. 실제 열차 시각·매장 대기·티켓 재고는 반영하지 않습니다. 좌표 미확인 장소는 동네 기준 위치로 구분합니다.
- 사진 392장(property 235, official 137, editorial 17, traveler 3). 사진이 없는 장소 34곳은 원문 링크를 제공합니다. 대표 명소 사진과 메이지신궁 11월 시간은 2026-10-29 보완했으며 항공·숙소 견적 조회일은 2026-10-28입니다.

## 추천 코스

`?suggestion=A#plan`, `?suggestion=B#plan`, `?suggestion=C#plan`으로 전통·건축카페·동네산책 추천을 미리 볼 수 있습니다. 기존 선택을 자동으로 덮어쓰지 않으며 전체 선택을 불러오거나 장소만 추가합니다. 세 안은 15:15 인천 출국 / 17:40 나리타 귀국, 비아 인 프라임 니혼바시 닌교초 3박을 가정합니다. 숙소가 바뀌면 시간표를 다시 계산합니다.

주변 로드뷰는 Google Maps URL을 새 창에서 여는 방식이며 API 키가 필요하지 않습니다. 공개 파노라마가 없는 위치는 Google 지도에서 주변 위치를 조정해야 할 수 있습니다. 공항 대표 좌표는 터미널 입구와 구분하고 실제 탑승 터미널의 길찾기를 안내합니다.
