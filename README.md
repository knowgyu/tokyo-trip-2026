# 도쿄에서 보낼 4일

2026년 11월 11~14일, 2인 도쿄 여행 계획.
항공·숙소 비교, 동네 지도, 명소·식당·카페 선택과 일정 생성을 제공하는 정적 웹페이지입니다.

선택한 장소와 일정은 방문자 각자의 브라우저에 저장됩니다.
항공·숙소 금액은 2026-10-28 조회 당시 표시가이며 실시간 예약 가격이 아닙니다.

## 실행

저장소의 루트를 정적 HTTP 서버로 열면 됩니다. 빌드 과정이나 API 키는 필요하지 않습니다.
GitHub Pages는 main 브랜치 루트를 게시합니다.

## 자료와 라이선스

- 지도: Leaflet 1.9.4 (BSD-2-Clause), OpenStreetMap contributors (ODbL).
- 글꼴: Pretendard. assets/의 라이선스 파일 참조.
- 장소·사진·후기·좌표의 출처는 화면 안에 표시되어 있습니다.
- 날씨 예보: Open-Meteo. 예보가 없는 날짜는 일본 기상청 평년값을 표시합니다.
